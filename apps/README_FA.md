# برنامه‌های مستقل نور قرآن

این پوشه تنظیمات ساخت نسخه‌های مستقل ویندوز، macOS، اندروید و iOS را نگه می‌دارد.

## خروجی‌ها
- ویندوز: فایل نصب‌کننده EXE و نسخه Portable
- macOS: فایل DMG و ZIP یونیورسال برای مک‌های Intel و Apple Silicon
- اندروید: فایل APK قابل نصب
- iOS: فایل IPA بدون امضا برای مرحلهٔ امضای نهایی در Xcode

برنامه‌ها صفحه‌های سایت را از فایل‌های همراه خودشان اجرا می‌کنند؛ برای باز شدن برنامه، مرورگر لازم نیست و صفحهٔ اصلی از یک آدرس اینترنتی بارگذاری نمی‌شود. برای دریافت اطلاعات زندهٔ قرآن، ترجمه‌ها، همگام‌سازی مدیر و برخی صداها همچنان اینترنت لازم است. فایل‌های صوتی‌ای که داخل برنامه دانلود می‌شوند روی همان دستگاه نگه‌داری می‌شوند.

## ساخت محلی
به Node.js 24 یا جدیدتر نیاز است.

```sh
npm install
npm run prepare:site
npm run build:windows
npm run build:mac
```

برای اندروید، Android Studio و Android SDK لازم است. پس از آماده‌سازی سایت:

```sh
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

فایل APK خروجی در `android/app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## iOS
برای ساخت پروژهٔ native به macOS و Xcode نیاز است. پروژه با شناسهٔ `ir.noorquran.ios` ساخته می‌شود. فایل IPA در CI بدون امضا بسته‌بندی می‌شود؛ این فایل به‌تنهایی روی آیفون واقعی قابل نصب نیست. برای نصب روی دستگاه یا انتشار در App Store باید با Apple Developer و Xcode امضا و provision شود.

## امضا و انتشار
ساخت macOS در حال حاضر بدون Developer ID و notarization انجام می‌شود؛ ممکن است macOS هنگام باز کردن فایل دانلودی هشدار ناشر ناشناس نمایش دهد. برای انتشار رسمی و نصب ساده، امضای معتبر و notarization اپل لازم است.

ساخت خودکار خروجی‌ها در GitHub Actions انجام می‌شود و فایل‌ها در صفحهٔ Releases مخزن منتشر می‌شوند.
